# Product & web UI

## Product vision

- One always-visible user prompt captures the human's drawing intent; **Go** applies it via the **intent** path (default LangChain agent + diagram tools), grounded in the user's own wording.
- **Gilfoyle**, **Dinesh** (both radial-labeled **Refine**), **Erlich** (**Innovate**), **Barker** (**Prep for the CEO**), and **Russ** (streak-dependent label — Russ → This Guy Ships → Tres Commas → Radio Silence) reuse the same tools but run under a **transform** agent with mode-specific prompts and sampling (hotter for bolder modes).
- **Jared** (radial **Critique**) and **Richard** (radial **Explain**) run read-only analysis into an insights pane; **Fix** turns critique into a diagram edit by reusing the **intent** path (the web app sends a long structured prompt as if it were a user request); **Show Thinking** streams agent telemetry into the same pane (SSE). **Show Thinking** button and icon are hidden until the first thinking event occurs in the session.
- Optional focus on a diagram node or edge narrows transforms, explanations, and critique-driven fixes to that subgraph.
- Switching between **Auto**, **Diagram**, **Infographic**, **3D**, **Chart**, **Anything**, and **Forms** modes preserves all canvases independently; **Auto** classifies the topic with a fast LLM on Go and switches into the best concrete mode. The active content type is forwarded in every agent call so the right agent and validator handles the request. **Forms** is the parody mode where the agent authors interactive A2UI intake forms directly (fill controls → submit → the next, worse form); see [Content types](content-types.md#forms).
- The tool sits inside an **office**: a cast of fifteen who email you, walk by, argue, and call meetings, rendered two ways — the **parody-OS workstation** you work in (menu bar, canvas, composer band, taskbar) and the **isometric floor** you stand up into. It is one state with two renderers ([ADR-0011](../decisions/0011-two-office-renderers.md)), and the cast **never produces slot content** ([ADR-0010](../decisions/0010-cast-agency-sign-off.md)) — of the five things you can do with them, only **delegate** spends a pipeline run ([ADR-0012](../decisions/0012-collaboration-model.md)). Everything they say can carry a **pitch**: a suggestion with a button that runs _your_ pipeline, attributed to whoever proposed it. Full spec: [`office-parody.md`](../office-parody.md), [`office-isometric-mode.md`](../office-isometric-mode.md).

## Web UI (what you see)

| Area                         | Role                                                                                                                                                                                                                                                                                                                                       |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Canvas**                   | Live Mermaid SVG or AntV Infographic render; click nodes/edges to set **focus** for scoped transforms and critique.                                                                                                                                                                                                                        |
| **Monaco editor**            | Source for the active slot; syncs to the server on edit. Mermaid render errors and Anything load-phase runtime errors trigger debounced **auto-fix** (fast-path `POST /api/diagram/render-error` first, then intent fallback).                                                                                                             |
| **Prompt bar + radial menu** | **Go**, **Gilfoyle** / **Dinesh** (**Refine**), **Erlich** (**Innovate**), **Russ**, **Barker**, **Jared** (**Critique**), **Fix** (when critique is actionable), **Richard** (**Explain**), **Style** (Mermaid and Chart). On narrow viewports the same actions live in a **radial menu** over the canvas (`buildRadialActions.jsx`).     |
| **Insights / Thinking pane** | Streaming tokens with **generative micro-viz** (hex swatches, color ramps, icon replace chips), plan cards, patch sparkbars, tool stepper, and critique output. **Show Thinking** mirrors AG-UI phases; critique **Fix** uses checkboxes (A2UI); style tweak lines render as **Visual tweaks** cards (`style_edits` artifact).             |
| **Menu bar + taskbar**       | The parody-OS frame. Top: brand (leading slot), Deliverable, Mailroom, View, Admin. Bottom: **Stand up**, the **presence strip** (who is around, and a second way onto the floor), the open-window list, and a tray carrying run status, Concentration and XP. Chrome is a thin frame — the canvas stays fixed and maximized between them. |
| **Talk lane**                | The second composer, beside the Work Order. Says something to the room (or to one person, via the roster) and costs no pipeline run — replies land as speech at your desk.                                                                                                                                                                 |
| **Office moments**           | Inbox, Slop Chat™, walk-bys, coffee breaks, cubicle battles, meetings, and **mob** / **pair** huddles around your canvas. Interruptions are timer-driven and budgeted; the isometric floor renders the same moments as a room you can walk around.                                                                                         |
| **Agent presence bar**       | External agents that completed handshake; emoji reactions and focus highlights from the room.                                                                                                                                                                                                                                              |
| **Handshakes & proposals**   | Dialog when an MCP guest requests join; proposal cards when a guest submits an edit (accept / reject / request changes).                                                                                                                                                                                                                   |
| **Invite agent**             | Pairing code, QR, **Add to Cursor** / **Install in VS Code** deeplinks, rotate code.                                                                                                                                                                                                                                                       |
| **Slopitect** (cosmetic)     | Companion avatar, run HUD, streaks, and session achievements — feedback on agent runs, not a separate backend.                                                                                                                                                                                                                             |
| **Metaphor3D fullscreen**    | Native-fullscreen canvas for the 3D slot. An in-canvas pill lets the viewer switch spatial metaphor kinds (city → terrain → galaxy …) without leaving fullscreen; a × exit button is always visible. The proactive Advisor loop is paused while fullscreen is active so it doesn’t pulse nodes over a bare canvas.                         |

Built-in agents never bypass validation; external agents never auto-apply (proposals only).
