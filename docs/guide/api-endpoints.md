| `POST` | `/api/signals`                                  | Content-free usage signals for ArchiSlop God (ADR-0019). Body `{ v: 1, signals: [...] }` validated against the strict client union in `packages/shared/src/uxSignals.ts` (enums, bounded integers and booleans only; max 50 per batch, 16 KB). JSON or a `text/plain` beacon body. Always `204` when accepted _or_ when signals are off; `400` invalid, `413` too large, `429` per client IP (`req.ip`). Each signal becomes one `ux_signal` stdout line; nothing is stored or echoed.                                                                                                                                                                                                                                                                                                                                                            |
| `GET`  | `/api/god/status`                               | ArchiSlop God's own run history for the owner (ADR-0019 §10). Reads the `god-log` month rollup over `raw.githubusercontent.com` — no credential, because the repo is public and every field God writes is content-free. Returns `source` (`live` / `stale` / `none`), `numbersFrom` (`records` = the month totals the fold stamped from `runs/*.json`, `rollupRows` = only the rows that survived), `ticks`, `acts`, `monthSpendUsd`, `lastTick` (with its recorded `gateReason`, brief `digest` and `narration` outcome), `lastActAt`, `lastActNarration`, `unproductiveActs` / `unproductiveUsd` and a `reasonTally`, so "why has it done nothing?" is answerable after the CI log expires. `200` live or stale, `503` when nothing is readable. Owner-only behind `GOD_WINDOW_TOKEN` (next row), not the door code. `Cache-Control: no-store`. |
| `POST` | `/api/god/unlock`                               | Exchange the owner token for the God-window cookie (ADR-0019 §10). Body `{ token }`; on success sets `archislop_god_window` — HttpOnly, `SameSite=Lax`, `Path=/api/god`, 12 h — and returns `{ ok: true }`. `401` wrong or missing token; `503` when `GOD_WINDOW_TOKEN` is unset, which is fail-closed: with no token the whole `/api/god/*` surface answers `503`, so a deployment that forgot the secret publishes nothing. The cookie is signed with `GOD_WINDOW_COOKIE_SECRET`, or a key derived from the token when that is unset — never the visitor-badge fallback — and its payload carries `scope: "god"`, which is what stops a visitor-badge cookie from opening the window even if the two secrets ever coincide.                                                                                                                     |
| `POST` | `/api/god/live`                                 | Runner-only live harness ingest (ADR-0019 §10). Raw JSON body `{ runId, events }` validated against `GodLiveBatchSchema`; authenticated with `x-god-timestamp` + `x-god-signature` (`HMAC-SHA256` over `"<timestamp>.<body>"` via `GOD_INGEST_SECRET`). Not behind the owner cookie. `204` accepted; `400` invalid; `401` stale or bad signature; `409` replayed `seq`; `503` when `GOD_INGEST_SECRET` is unset. Best-effort — durable memory stays on `god-log`.                                                                                                                                                                                                                                                                                                                                                                                 |
| `GET`  | `/api/god/live/:runId`                          | Owner read of the in-memory live buffer. Query `after=<seq>` (default `0`). Returns `{ v, runId, afterSeq, lastSeq, events }`. Owner cookie required (same gate as `/api/god/status`). `Cache-Control: no-store`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
