## Open observations

- `apps/web/src/utils/metaphorFlatItemsCore.js` is genuinely shared infrastructure for city/garden/the flat-kind factory, but it does **not** match this playbook's `allowedPaths` glob `apps/web/src/utils/metaphor*Edit.js` (it doesn't end in `Edit.js`). Any slice that wants a shared helper there needs the playbook's `allowedPaths` widened first, or (as done tonight) keep the helper private to the one mutator file that needs it.
- Issue #447 (three lint `complexity` warnings in graph-edit mutators, including `infographicGraphEdit.js` and `mermaidClassEdit.js`) was filed by the `improve` routine's own audit and its body explicitly defers to "a future `improve` run (or a human)" — left for `improve`, not taken as this automation's work.
- `docs/automations/canvas-graph-edit.md`'s `allowedPaths` names `useFlowchartGraphEdit.js` and `useCanvasGraphEdit.js` (pre-emptively, for the pending `hook-rename` slice) under `apps/web/src/hooks/`, but the hook has actually lived under `apps/web/src/features/canvas/` since before this playbook was written — the glob has never matched the real file (confirmed with `find`; that `hooks/` path resolves nowhere). `routine-guard` matches the literal relative path, not the basename, so any slice needing to edit the hook is `blocked-by-paths` until `improve` corrects the directory in both globs (found 2026-09-01 while scoping #402; #402 itself needs this fix before it's takeable — see the run-log row above). Still unfixed as of 2026-09-03; #510 (queued 2026-09-02) hits the identical wall.
- **The family table's "shipped" column means mutator + adapter + unit tests, not necessarily reachable-from-canvas.** Confirmed this the hard way for pie (#523) — the precedent already existed for Metaphor3D edges (#495) but this is the first time it's shown up on a **node**-level family, not just edge rename/delete. Before starting a mutator for any family whose table row doesn't explicitly say "canvas resolves clicks via …" (compare timeline's row, which does), render the diagram type through the pinned mermaid/AntV version first and check its DOM against the six `g.node`/`g.timeline-node`/`g.cluster` call sites listed in #523 — don't trust the table's "shipped" alone.
