  not scoped to mindmap. Spec axis flagged it as a latent edge case (a flowchart node literally named

  ids today. Watching, not filing.

  fix, not duplicated here.
- **2026-08-26 — `metaphorFlatKindEdit.js`'s `isFamilySource` field is built into every one of the
  11 kinds' returned objects but never read anywhere** (`flatGraphEditAdapter` doesn't consult it;
  `metaphorFlatGraphEditForSource` sniffs `doc.metaphor` against the registry directly instead) —
  Standards axis, Fowler "Speculative Generality." Single unused object property, invisible to
  tooling (not a variable, so `no-unused-vars` can't see it). Matches the precedent of the
  2026-08-21 `dayStampOf` finding: cosmetic, recorded here rather than filed.

  before export (Fowler "Middle Man," flagged as a nit by the reviewing agent itself) — but it
  mirrors the repo's existing `connect{Family}Nodes` naming convention used by the city/garden
  adapters in `canvasGraphEdit.js`, so this reads as intentional consistency rather than a defect.
  Watching, not filing.
- **2026-08-27 — `mermaidSourceLocate.js` now carries two independently-defined sequence-arrow
  grammars**: the new `SEQUENCE_MSG_LINE_RE` (broad arrow-character class, used only to index
  messages for `messageId`-based lookup) and the pre-existing per-call `arrowRe` (narrow arrow-type
  allowlist, used only for the legacy label-based fallback path) — Standards axis, Fowler
  "Duplicated Code" / latent "Shotgun Surgery." Traced both call paths: they are self-consistent
  independently (messageId lookup never consults `arrowRe` and vice versa), and no arrow shape in
  today's supported grammar makes the two disagree, so this is a forward maintenance risk rather
  than a reproduced bug — same class as the 2026-08-21 `graphEditIdFromDescriptor` finding
  ("latent edge case... not a reproduced bug... watching, not filing"). Watching, not filing.
- **2026-08-27 — `metaphorCompositeEdit.js`'s `layerDelegate` is a fourth kind-dispatch switch**
  (tree/city/garden/flat-kinds) returning the identical 6-key mutator shape from four different
  import sources, alongside the pre-existing `graphEditAdapterFor` dispatcher in
  `canvasGraphEdit.js` — Standards axis, Fowler "Repeated Switches." Not a CLAUDE.md violation (the
  family-table convention already accepts one mutator+adapter row per kind) and adding a fifth base
  kind means touching both regardless of shape; cosmetic, recorded here rather than filed.
- **2026-08-27 — `metaphorCompositeEdit.js`'s `ensureGloballyUniqueId` mutates `item.id` in place**
  on the parsed doc rather than returning a new value, which its name doesn't signal — Standards
  axis, Fowler "Mysterious Name." Harmless (call sites rely on the mutation), single-instance,
  cosmetic. Recorded here rather than filed.
